## Etap 2 — nie bierz pierwszej rekomendacji w ciemno

Po researchu agent zrobi scoring platform. W lekcji przykład pokazuje, że Cloudflare Workers może wygrać, ale trzeba jeszcze zrobić testy anti-bias. 

Poproś agenta:

```text
Before we accept Cloudflare, run anti-bias checks:
1. Devil's advocate — why is Cloudflare a bad choice for this project?
2. Pre-mortem — imagine we regret this decision after 3 months. What happened?
3. Unknown unknowns — what risks were not included in the scoring?
```

Potem podejmij jedną z 3 decyzji:

```text
Accept the risk and continue.
Add this risk to infrastructure.md.
Reconsider the platform.
```

## Sekcja, którą chcesz mieć w `deploy-plan.md`

````markdown
## Prerequisites — one-time setup for a new project

### 1. Wrangler CLI

Use Wrangler through `npx`:

```bash
npx wrangler --version
npx wrangler login
npx wrangler whoami
````

Do not assume the user is logged in. Always verify with `whoami`.

### 2. Cloudflare account

Create a free Cloudflare account.

Manual steps:

* go to Cloudflare dashboard
* create account
* verify email
* confirm account access

Agent can verify access only after Wrangler login:

```bash
npx wrangler whoami
```

### 3. GitHub CLI

Install GitHub CLI and login:

```bash
gh --version
gh auth login
gh auth status
```

Use this for repo, PR, and deployment verification tasks.

### 4. Supabase remote project

Create a Supabase project manually.

Required values:

* Supabase project URL
* publishable / anon key

Do not use the `service_role` key in frontend or public runtime.

### 5. Supabase local setup

Local Supabase requires Docker.

Verify Docker:

```bash
docker --version
docker ps
```

Start local Supabase:

```bash
npx supabase start
```

The command will output local values such as:

* local API URL
* anon key
* database URL

Add local values to `.env.local`.

### 6. Environment variables / secrets

Local:

```env
SUPABASE_URL=
SUPABASE_KEY=
```

Cloudflare:

```bash
npx wrangler secret put SUPABASE_URL
npx wrangler secret put SUPABASE_KEY
npx wrangler secret list
```

### 7. Human approval boundaries

Agent can:

* inspect repo
* update config files
* run local builds
* verify CLI access
* prepare deployment commands

Human must:

* create accounts
* approve Cloudflare login
* copy Supabase secrets
* approve production deployment
* perform destructive actions manually

