Jasne. **M1L2 = wybór stacku przez skill, nie przez luźny prompt.** Celem jest wygenerowanie pliku **`context/foundation/tech-stack.md`**, który potem czyta M1L3 bootstrapper. 

## M1L2 — step by step dla Twojego 10xCards

### 1. Pobierz lekcję

W katalogu projektu:

```bash
npx @przeprogramowani/10x-cli@latest get m1l2
```

To pobiera skille z lekcji, głównie:

```text
/10x-tech-stack-selector
/10x-stack-assess
```

### 2. Upewnij się, że masz PRD

Powinieneś mieć po M1L1:

```text
context/foundation/prd.md
```

Opcjonalnie też:

```text
context/foundation/shape-notes.md
```

### 3. Uruchom skill dla greenfield

Dla Twojego projektu 10xCards użyj:

```text
/10x-tech-stack-selector @context/foundation/prd.md
```

Skill czyta PRD, zadaje pytania i zapisuje decyzję jako **`tech-stack.md`**. To ważne, bo ad-hoc prompt może dać losową rekomendację, ale skill daje format zgodny z kolejnym krokiem kursu. 

### 4. Jak odpowiadać na pytania skilla

Dla Twojego projektu zaliczeniowego sugerowałbym:

```text
Language family: JavaScript / TypeScript
Recommended starter: 10x Astro Starter
Deployment: Cloudflare Pages
CI/CD: GitHub Actions
Deployment flow: manual deploy albo deploy przez PR/merge — zgodnie z tym, co skill rekomenduje
Project name: 10x-cards
```

W lekcji rekomendowany stack to Astro + TypeScript + React + Tailwind + Supabase, bo jest najlepiej spięty z dalszym bootstrapperem. 

### 5. Sprawdź output

Po zakończeniu powinieneś mieć:

```text
context/foundation/tech-stack.md
```

Sprawdź, czy na górze ma frontmatter podobny do:

```yaml
starter_id: 10x-astro-starter
bootstrapper_confidence: first-class
path_taken: standard
has_auth: true
has_ai: true
has_payments: false
```

To jest kontrakt dla M1L3. Bootstrapper później patrzy na `starter_id` i wie, jak wygenerować projekt. 

## Kiedy używać `/10x-stack-assess`

To nie jest dla Twojego 10xCards, jeśli zaczynasz od zera.

Używasz tego dla istniejącego projektu, czyli brownfield:

```text
/10x-stack-assess
```

Wynik:

```text
context/foundation/stack-assessment.md
```

Ten skill nie wybiera nowego stacku, tylko ocenia obecny: typowanie, konwencje, popularność i dokumentację. Potem daje plan kompensacji dla agenta. 

## Mój prosty workflow na przyszłość

Dla nowego projektu:

```text
M1L1: /10x-shape → /10x-prd
M1L2: /10x-tech-stack-selector
M1L3: /10x-bootstrapper
M1L4: AGENTS.md / CLAUDE.md / Cursor rules
```

Dla istniejącego projektu:

```text
M1L2: /10x-stack-assess
M1L3: /10x-health-check
M1L4: AGENTS.md / CLAUDE.md / Cursor rules
```

Najważniejsza zasada z tej lekcji: **ważne skille wywołuj jawnie**, nie licz na automatyczną aktywację.
