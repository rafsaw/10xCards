# Why this model?

Z lekcji:

* Claude preferuje `CLAUDE.md`
* Codex preferuje `AGENTS.md`
* Cursor czyta `AGENTS.md`
* nested rules są silniejsze niż giant root file 
* duplikacja rules = bad
* generated init output = only draft, never final 

więc:

**jedna prawda + cienkie adaptery**

```bash
AGENTS.md
```

## project context

```md
10xCards is a flashcard learning app built as a 10xDevs3 graduation project.
```

---

## architecture rules

```md
Frontend and backend are separate concerns.

UI components should remain presentation-focused.

Business logic belongs in services/use-cases.

Persistence logic belongs in repositories.
```

---

## coding conventions

```md
TypeScript strict mode.

Prefer absolute imports.

Reuse existing abstractions before creating new ones.
```

---

## anti-patterns

IMPORTANT

```md
Avoid:
- duplicate DTOs
- speculative abstractions
- unnecessary wrappers
- dead code
- introducing new dependencies casually
```

## testing

```md
Run lint/tests before declaring completion.
Never claim success without execution.
```
